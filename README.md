# pixelpastahtml

a pixel horror / creepycore html theme for neocities.

[download the theme](https://github.com/numbpill3d/pixelpastahtml/archive/refs/heads/main.zip) · [browse my neocities themes](https://github.com/numbpill3d#neocities-theme-gallery)

## use on neocities

1. download and unzip the theme files.
2. keep `index.html`, `style.css`, and `scripts.js` together. in `index.html`, change the script source from `script.js` to `scripts.js` so it matches the included file.
3. replace the sample text, links, and placeholder image paths with your own content.
4. back up your current neocities files, then upload the theme files through your neocities dashboard.
5. visit your site and check the layout, images, and interactions.

## make it yours

change the colors, text, navigation, and images to fit your own little corner of the web. no build step is needed.
